# Documentation

The reviewer-facing material is organized as follows:

- [`migration-approach.md`](migration-approach.md) — proposed Gen 1 to Gen 2 migration approach.
- [`migration-approach-presentation.md`](migration-approach-presentation.md) — concise presentation source.
- [`presentation-speaker-notes.md`](presentation-speaker-notes.md) — detailed walkthrough and supporting explanations.
- [`presentation-runbook.md`](presentation-runbook.md) — reproducible demonstration commands and evidence guide.

Generated workbooks, logs, archives, and local database fixtures are supporting
evidence rather than source code. They are intentionally excluded from the
reviewable Git history by `.gitignore`.
